# bt-manager — خطة التطوير التنفيذية (ملخص الإصدار 0.2)

## قرارات المنتج
- تثبيت محلي لكل مشغّل شبكة؛ لا تعدد مستأجرين أو تراخيص/خطط اشتراك في MVP.
- أول بيئة تسليم Windows مع اختبار اتصال LAN براوتر MikroTik عبر RouterOS API/API-SSL.
- Go للخادم والمنطق، وReact + TypeScript + Bootstrap RTL لواجهة الويب وسطح المكتب المشتركة.
- SQLite محلية تديرها عملية واحدة؛ لا حاجة إلى PostgreSQL أو Docker أو Node.js وقت التشغيل النهائي.
- عملة واحدة تُحدد في الإعداد الأولي وتُقفل بعد أول معاملة مالية.
- نطاق MVP: اتصال الراوتر، وظائف HotSpot وUser Manager حسب التوافق المثبت، إنشاء دفعات القسائم، استوديو كروت، PDF، ونقاط بيع أساسية.
- المحرر يدعم خلفية مستوردة أو تصميمًا داخليًا، ومواضع متغيرات، وتخطيط A4 مرن. حالات القبول: 60 بطاقة (4×15 أو 3×20) و45 بطاقة (3×15).
- خادم الويب مقيد إلى loopback حتى اكتمال المصادقة وHTTPS وحماية الطلبات.

## المراحل وبوابات القبول
0. **جاهزية SDK:** اختبار مكتبة RouterOS بدقة وتصحيح السلوك غير السليم؛ تجربة فعلية على Windows/راوتر LAN وتحديد مصفوفة توافق v6/v7.
1. **أساس التطبيق:** Go، API موثقة، SQLite ومهاجرات، الإعداد والعملة، واجهة RTL، CI واختبارات.
2. **اتصال الراوتر:** اختبار اتصال آمن، معلومات النظام، اكتشاف الإمكانات وحماية الأسرار.
3. **HotSpot/User Manager:** محولات typed، توافق منفصل لـv6 وv7، قوائم وملفات ومستخدمون وجلسات.
4. **القسائم:** توليد دفعات، تقدم المهام، تسجيل الفشل ومنع التكرار غير المقصود.
5. **استوديو الكروت:** أصول وخلفيات ومتغيرات ومعاينة، قياسات mm، خطوط عربية وPDF واختبارات A4.
6. **POS:** نقاط بيع وإسناد مخزون ومبيعات ومرتجعات وتقارير أساسية بعملة واحدة.
7. **التقوية والتوزيع:** النسخ الاحتياطي والاستعادة والأمان والأداء وحزمة Windows ودليل الإعداد.

## معايير إصدار MVP
1. تثبيت وتشغيل Windows بلا PostgreSQL أو Docker أو Node.js وقت التشغيل.
2. اتصال LAN موثق وتوافق مثبت للأوامر المدعومة.
3. نجاح تخطيطات طباعة 60/4×15 و60/3×20 و45/3×15 بقياسات فعلية.
4. عملة واحدة ثابتة بعد أول معاملة وحسابات POS دقيقة.
5. نجاح النسخ الاحتياطي والاستعادة وعدم تسريب الأسرار.
6. عدم فتح LAN قبل المصادقة وHTTPS.

## مؤجل
SaaS، تعدد المستأجرين، الخطط والتراخيص، تعدد العملات، POS دون اتصال، أوامر RouterOS الخام في UI، والذكاء الاصطناعي.
